About This Repo

This repository is dedicated to exploring Web3 technologies: smart contracts, decentralized applications (DApps), blockchain interactions and more.

Project Goals

  • Understand the fundamentals of blockchain and Ethereum.
  • Develop and deploy smart contracts.
  • Create simple DApps to interact with contracts.
  • Experiment with token standards, governance, and Web3 tooling.

Commit Progress

Daily commits will capture incremental progress: setups, experiments, tutorials, code snippets and reflections. Feel free to check the commit history to follow along.

Getting Started

Clone the repo, install dependencies, and start experimenting. Contributions and suggestions are welcome.
